## 🌐 About This Website

A responsive portfolio built with plain HTML, CSS and JavaScript, with no frameworks or build step. It has a dark/light theme toggle, a mobile-friendly layout and a downloadable resume.

```
├── index.html    # page structure and content
├── styles.css    # layout, colours and themes
├── script.js     # theme toggle and scroll effects
├── resume.pdf    # resume
└── README.md
```

### Run it locally

1. Download or clone this repository
2. Open `index.html` in any browser

### Deploy with GitHub Pages

1. Go to **Settings → Pages**
2. Set **Source** to *Deploy from a branch*, choose `main` and `/ (root)`, then save
3. Your site goes live at `https://venkatachandu1011.github.io/VenkataChandu_Portfolio/`
